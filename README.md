# 논서술형 평가 도우미 v4.0

영쌤클래스의 Google Drive 기반 평가 준비·AI 초안·교사 검토 도구입니다.

## 사용 흐름

1. Google 로그인 후 기존 평가 시트를 연결하거나 새 시트를 만듭니다.
2. 평가 문항과 모든 척도의 판정 기준을 저장하고 학급 명단을 등록합니다.
3. 설정에서 Gemini API 키를 저장하고 모델 목록 갱신·연결 테스트를 실행합니다.
4. 평가의 답안 PDF를 등록하고 학생별 이름·번호·페이지를 확인합니다. 결시생의 빈 답안지 포함 여부를 구분합니다.
5. AI 초안 생성을 실행합니다. 결과는 문항마다 저장되며, 일시정지·실패 시 미완료 작업을 재개할 수 있습니다.
6. 검토 화면에서 원본·인식 텍스트·기준별 점수를 대조합니다. 교사가 모든 기준 점수와 종합 등급을 선택하여 확정합니다.
7. 확정 결과는 CSV와 인쇄/PDF로 내보낼 수 있습니다. 기준 답안 저장 후 동일한 기준 버전의 다음 채점에 참고됩니다.

로그인 전 **샘플 평가 둘러보기**는 가상 자료만 사용하며 Google 저장 및 AI 요청을 하지 않습니다.

## 기존 자료 호환

- 기존 9개 시트의 앞쪽 열 순서를 유지합니다.
- `학생페이지매핑` 끝에 PDF파일ID·매칭방식·결시빈답안포함을 추가합니다.
- `채점작업`, `채점이력` 시트를 추가합니다. 기존 시트의 열 개수가 부족하면 확장합니다.
- 기존 Apps Script 결과는 덮어쓰지 않습니다. 상세 작업 기록이 없는 이전 결과는 기존 시트에서 확인하도록 안내합니다.
- 루브릭·문항·명단·매핑·채점 저장은 Sheets `batchUpdate`로 묶어 삭제와 추가를 함께 적용합니다.
- 한 시트는 한 기기에서 편집/채점하세요. 같은 브라우저의 탭 간 작업은 Web Locks로 조정하지만 서로 다른 기기의 동시 수정 충돌까지 방지하지는 않습니다.

## 검토 원칙

- AI 응답은 루브릭의 기준 번호·척도/점수 쌍을 검증한 후 검토 대기로 저장합니다.
- 무응답·판독 불가는 점수를 추측하지 않고 교사 확인 상태로 남깁니다.
- AI 최초 응답과 교사 수정 내용·확정 이력을 구분합니다.
- 종합 등급은 학교 평가 계획에 따라 교사가 직접 선택합니다. 자동 비율/문항분포 등급 계산은 제공하지 않습니다.
- 모델 연결 테스트는 짧은 JSON 생성 호출만 검증합니다. 손글씨 인식·교육적 타당성을 보장하지 않습니다.
- 중단 작업의 기준·모델·답안 연결이 변경되면 자동으로 섞어 채점하지 않습니다. 미완료 기록을 이력에 보관한 뒤 초기화하여 재시작합니다.

## 저장·개인정보

본인 Drive에 PDF와 평가 기록을 저장합니다. AI 사용 시 답안 페이지 이미지 또는 교사가 수정한 텍스트와 문항·기준을 Gemini에 전송합니다. 이미지에 보이는 개인정보도 포함될 수 있습니다. 브라우저의 임시·복구 기록은 계정·시트별로 구분하며 설정에서 삭제할 수 있습니다. API 키는 코드에 포함하지 않고 사용자가 입력합니다. Picker용 API 키도 공개 소스에서 제거했습니다. Google 파일 선택 창이 필요하면 설정에서 동일 OAuth 프로젝트의 Picker API 키를 브라우저에 저장하세요. 기존 연결 시트·새 시트 생성·직접 업로드에는 필요하지 않습니다. 이전에 이 앱에 접근을 허용한 시트는 주소로 연결할 수도 있습니다.

## 구조와 검증

- `app.js`: 기존 로그인·Drive·평가/루브릭·PDF 기능
- `workspace.js`: 저장 일관성·워크스페이스·임시저장·매핑 보완
- `grading.js`: 채점 작업·복구·교사 검토·통계·출력·샘플
- `core.js`: 점수·페이지·저장 요청 검증 (순수 함수)
- `boot.js`, `workspace.css`, `index.html`: 초기화·화면

Node.js 20 이상에서 `npm ci`, `npm run check`, `npm test`로 검증합니다. 테스트는 가상 DOM과 모의 API를 사용합니다. 실제 Google OAuth·Drive 저장·Gemini 응답은 유효한 계정/키로 별도 확인해야 합니다. 공개 앱을 검사할 때 실제 학생 데이터를 사용하지 않습니다.
