개인정보 처리 안내

논서술형 평가 채점 시스템 (웹앱) · 시행일 2026년 10월 8일
이 앱은 서버가 없습니다. 앱이 다루는 모든 데이터는 선생님 본인의 Google Drive와 사용 중인 브라우저에만 저장되며, 개발자(영쌤클래스)를 포함한 제3자에게 전송·수집되지 않습니다.

1. 수집·저장하는 정보와 위치

  • Google 계정 정보(이메일·이름): 로그인한 사용자를 화면에 표시하기 위해서만 사용하며, 브라우저에만 저장됩니다.
  • 평가·루브릭·학생 명단·채점 결과: 선생님 본인 Google Drive의 스프레드시트에 저장됩니다. 개발자는 접근할 수 없습니다.
  • 학생 답안 PDF: 선생님 본인 Google Drive의 폴더에 저장되며, 채점 시 선생님의 Gemini API 키로 Google Gemini API에 전송되어 분석됩니다.
  • Gemini API 키: 선생님이 직접 발급해 입력한 키로, 사용 중인 브라우저(localStorage)에만 저장되고 Gemini 호출 시에만 사용됩니다.

2. 요청하는 Google 권한

  • drive.file: 이 앱이 만들었거나 선생님이 직접 선택한 파일만 읽고 씁니다. Drive의 다른 파일에는 접근하지 않습니다.
  • openid, email, profile: 로그인 사용자 표시용.

3. 제3자 전송

  • 학생 답안과 채점 지시문은 선생님의 API 키로 Google Gemini API에 전송됩니다. 이 처리는 Google의 Gemini API 이용약관을 따릅니다. 유료 API를 사용하면 입력 데이터가 모델 학습에 사용되지 않습니다.
  • 그 외 어떤 서버나 서비스에도 데이터를 보내지 않습니다.

4. 학생 개인정보 보호를 위한 권고

  • 답안 PDF와 학생 명단에는 교육 목적상 필요한 최소 정보(번호·이름)만 포함하세요.
  • 학생 정보가 담긴 스프레드시트와 폴더는 다른 사람과 공유하지 마세요.
  • 채점이 끝난 답안 PDF는 학교 규정에 따라 보관하거나 삭제하세요.
  • 공용 컴퓨터에서는 사용 후 설정에서 API 키를 삭제하고 로그아웃하세요.

5. 데이터 삭제

  • 스프레드시트·폴더·PDF는 선생님이 Drive에서 직접 삭제할 수 있습니다.
  • 브라우저에 저장된 설정(API 키, 연결 정보)은 앱 설정에서 삭제하거나 브라우저 사이트 데이터를 지우면 삭제됩니다.
  • Google 계정 설정 → 보안 → 서드파티 앱에서 이 앱의 권한을 언제든 철회할 수 있습니다.
