선생님의 평가 작업실

준비부터 피드백까지, 평가 하나씩 차근차근.

평가는 단일 문항(답안 1장에 문항 1개) 또는 다중 문항(여러 문항, 소문항 1-1·1-2 가능, 한 페이지에 여러 문항 가능)으로 만듭니다. 문항별 모범답안·핵심요소를 넣으면 채점 일관성이 크게 올라갑니다. 평가를 만든 뒤 루브릭 설정에서 문항별 채점 기준을 정하세요.

Gemini API 키

AI 채점에는 Google Gemini API 키가 필요합니다. 여기서 발급받을 수 있습니다. 키는 이 브라우저에만 저장되며 어디로도 전송되지 않습니다(Gemini 호출 시에만 사용).

AI 모델 선택

키로 조회한 모델 중 생성 기능을 지원하는 모델을 선택합니다. 모델 변경 후 연결 테스트를 실행하세요. 실제 답안 인식 품질은 대표 답안으로 확인해 주세요.

💡 유료 API: 결제가 등록된 키만 넣으면 자동으로 높은 한도가 적용됩니다. 별도 설정은 없습니다.

기본 채점 속도

기본은 30초 간격입니다. 호출 한도 오류가 발생하면 대기 후 재시도합니다. 한도는 계정·모델에 따라 다르며 속도가 성공을 보장하지 않습니다.

시스템 진단

로그인·시트·API 키 상태를 한눈에 확인합니다.

Drive 파일 선택기

이미 연결한 시트, 새 시트 만들기, 직접 PDF 업로드에는 추가 설정이 필요 없습니다. Google 파일 선택 창을 사용할 때만 설정합니다.

이 브라우저의 임시 기록

평가·루브릭 초안과 저장 실패 시 복구 기록에는 학생 정보가 포함될 수 있습니다. 공용 기기에서는 Drive 저장을 확인한 뒤 지워 주세요.
