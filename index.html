논서술형 평가 채점 시스템

AI가 답안을 읽고 루브릭에 따라 채점 초안을 만들고,
선생님이 검토·확정합니다. 모든 데이터는 선생님 본인의 Google Drive에만 저장됩니다.

요청 권한: 이 앱이 만들거나 선생님이 직접 고른 파일만 접근 (drive.file)
개인정보 처리 안내

📊

채점 데이터를 저장할 스프레드시트를 연결하세요

평가·루브릭·학생 명단·채점 결과가 모두 이 스프레드시트에 저장됩니다.
Apps Script 버전을 쓰셨다면 그 스프레드시트를 그대로 연결하면 기존 데이터가 이어집니다.

📂
기존 스프레드시트 연결 Apps Script 버전에서 쓰던 "서술형평가 채점 시스템" 시트를 고릅니다. 부족한 탭·열은 자동으로 보완됩니다.
✨
새 스프레드시트 만들기 내 Drive에 "서술형평가 채점 시스템" 시트를 새로 만들고 필요한 탭 9개를 자동 생성합니다.

Gemini API 키

AI 채점에는 Google Gemini API 키가 필요합니다. 여기서 발급받을 수 있습니다. 키는 이 브라우저에만 저장되며 어디로도 전송되지 않습니다(Gemini 호출 시에만 사용).

AI 모델 선택

모든 모델이 Gemini 3.x 세대로, 답하기 전에 '생각하는 단계'를 거쳐 채점 정확도가 높습니다. 일반적으로 3.7 Flash를 권장하고, 무료 API로 학생 수가 많으면 Flash-Lite, 정밀 채점이 필요하면 3.8 Flash나 3.1 Pro를 고르세요.

💡 유료 API: 결제가 등록된 키만 넣으면 자동으로 높은 한도가 적용됩니다. 별도 설정은 없습니다.

기본 채점 속도

여러 학생을 채점할 때의 진행 방식입니다. 유료 API라면 "초고속"으로 두면 훨씬 빠릅니다.
